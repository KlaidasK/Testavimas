# Selenium užduotys – Explicit Wait ir Unittest

Šiame projekte pateikiami du Python skriptai, kurie demonstruoja `Selenium WebDriver` naudojimą:  
viename panaudojamas explicit wait, o kitame – testavimas su `unittest`.

---

## Reikalavimai

- **Python** 3.8+  
- **Google Chrome** naršyklė  
- **ChromeDriver**, suderinantis su Chrome versija, turi būti įtrauktas į `PATH`  
- Reikalingi paketai:
- pip install selenium

- ## Naudojimas

1. Išsaugokite failus:
 - `1.py`
 - `2.py`

2. Paleiskite skriptą su explicit wait:
```bash
python 1.py
```

4. Paleiskite testus:
```bash
python -m unittest 2.py
```
