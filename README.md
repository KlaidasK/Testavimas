# Selenium + Pytest užduotys

Šiame projekte yra du Python testų failai, kurie demonstruoja `pytest` ir `Selenium WebDriver` naudojimą.  
Pirmas failas naudoja paprastą `fixture`, o antrasis – pažangesnį `fixture` valdymą su skirtingais scope bei autouse.

---

## Reikalavimai

- **Python** 3.8+  
- **Google Chrome** naršyklė  
- **ChromeDriver** (turi būti suderinamas su Chrome versija ir įtrauktas į `PATH`)  
- Reikalingi paketai:
```
pip install selenium pytest
```
## Naudojimas

1. Išsaugokite failus:
 - `1.py`
 - `2.py`

2. Paleiskite testus terminale:
```
pytest -v
```
