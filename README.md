# Selenium užduotys – Alert ir Redirect

Šiame projekte pateikiami **du Python skriptai**, kurie demonstruoja `Selenium WebDriver` naudojimą:  
vienas skriptas apdoroja puslapį su **JavaScript alert** langeliu, o kitas – puslapį, kuris atidaro naują langą (**redirect**).

---

## Reikalavimai

- **Python** 3.8+  
- **Google Chrome** naršyklė  
- **ChromeDriver**, suderinantis su Chrome versija, turi būti įtrauktas į `PATH`  
- Reikalingi paketai:
  ```bash
  pip install selenium
  
## Naudojimas

1. Išsaugokite failus:
 - `alert_task.py`
 - `redirect_task.py`

2. Paleiskite bet kurį skriptą
